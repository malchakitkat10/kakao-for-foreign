# 그림자 레이드 60 — 구현·검증 기록

기존 창작마당에 실제 플레이 가능한 대표 게임을 추가했습니다. 현재 Studio의 `game` 형식은 질문에 답해 유형 결과를 받는 구조이므로, 그 스키마에 전투 데이터를 끼워 넣지 않고 독립된 전투 엔진과 대화형 플레이어를 연결했습니다. 런타임 의존성, 외부 API, 서버, 새 IP 이미지 다운로드 없이 실행합니다.

## 게임과 진입 경로

- Playground 홈 첫 배너 → `60초 도전 · 1인 플레이`.
- 창작마당 전체·카카오페이지 분류 상단 → `그림자 레이드 60`.
- 게임명·IP명으로 검색해도 실행 카드가 표시됩니다.
- 게임 종료 후 복사한 `?raid=6자리코드&raidLang=ko#playground` 링크 → 같은 코드의 시작 안내. `raidLang=en`은 영어 안내입니다.

공식 에셋 `dist/assets/official/solo-leveling.jpg`를 그대로 재사용했습니다. 출처는 기존 `ASSET-SOURCES.md`에 유지되어 있습니다. 던전 코어와 전투 규칙은 이 프로토타입의 창작 요소이며 원작의 공식 게임 설정이라고 주장하지 않습니다.

## 규칙

| 요소 | 동작 |
| --- | --- |
| 목표 | 제한시간 60초 안에 체력 720의 던전 코어 파괴 |
| 플레이어 | 체력 100. 0이면 즉시 실패 |
| 공격 | 12 피해, 소환 게이지 +12, 공격·소환 공통 재사용 대기 0.65초 |
| 회피 | 0.6초 무적, 재사용 대기 1.4초. 회피 중 공격·소환 불가 |
| 공격 예고 | 예고 바와 문구로 충돌 시점을 알림. 마지막 0.55초에 `지금 회피` 표시 |
| 회피 성공 | 게이지 +25, 1.6초 안의 다음 일반 공격 30 피해. 보너스 1회 소비 |
| 그림자 소환 | 게이지 100을 소비해 100 피해 |
| 단계 | 코어 체력 480·240에서 단계 상승. 예고 시간이 짧아지고 피격 피해가 14→18→22로 증가 |
| 승리 | 코어 체력 0. 클리어 시간·회피 횟수·개인 기록 표시 |
| 패배 | 내 체력 0 또는 60초 초과. 남은 코어 체력 표시 |

버튼과 키보드 `A / D / S`는 채팅 명령과 같은 엔진 함수를 호출합니다. 채팅창은 한국어·영어 명령과 `/attack` 등 슬래시 접두어를 받습니다. 메시지를 입력해도 정답·분기 문장을 고르는 구조가 아니라 현재 시간, 재사용 대기, 체력, 게이지, 회피 상태에 따라 결과가 달라집니다.

입력 즉시 피해 숫자·회피 모션·체력 바·게이지·전투 메시지에 반영합니다. 모션 줄이기 설정을 따르며, 버튼의 준비 상태가 바뀌어도 키보드 초점은 유지합니다. 별도 일시정지 버튼이 있고 탭이 숨겨지면 자동 일시정지합니다. 복귀 후에는 계속하기를 눌러야 시간이 다시 흐릅니다. 닫기·Escape·해시 탐색 시 애니메이션 프레임을 정리합니다.

## 재도전과 관계 연결 범위

같은 코드와 같은 입력 타이밍은 같은 결과를 만듭니다. 같은 던전에서 더 빠른 클리어를 노릴 수 있고 새 던전은 예고·대기 타이밍을 바꿉니다. 코드별 최고 기록은 `playground-shadow-raid-v1`에 최대 20개 저장하며, 손상된 데이터와 저장 실패를 처리합니다.

친구에게 전달할 수 있는 것은 동일한 던전 패턴의 URL입니다. 수신자는 해당 브라우저에서 별도 게임을 실행합니다. 링크는 기존 도메인과 경로를 사용하며 불필요한 쿼리를 제거합니다. 클립보드 API가 차단되면 직접 복사할 수 있는 입력칸을 제공합니다.

| 구분 | 구현 상태 |
| --- | --- |
| 전투·판정·승패·재도전 | 실제 로컬 동작 |
| 한국어·영어 게임 화면 | 실제 로컬 동작 |
| 개인 최고 기록 | 실제 브라우저 저장. 다른 기기와 동기화되지 않음 |
| 도전 링크 | 같은 던전에 각자 도전. 함께 플레이하거나 상대 결과를 가져오지 않음 |
| 코어 공격·시스템 메시지 | 정해진 게임 로직. 다른 접속자나 AI 응답을 가장하지 않음 |
| 실시간 멀티플레이·매칭·공동 체력·서버 순위 | 미구현 |
| 카카오톡 실제 채팅 전송·SDK 연결 | 미구현. 사용자가 복사한 링크를 직접 전달 |
| Studio에서 이 액션 게임을 AI로 생성·편집 | 미구현. 이번 게임은 직접 구현한 대표 샘플 |
| 기존 홈 순위·기존 팬게임 목록 | 시연 데이터. 미리보기 카드에 표시 추가, 생존방의 인원 표기를 시연용으로 변경 |

현재 반복 동기는 조작 숙련과 개인 기록입니다. 장기 재방문율이나 실사용자 간 관계 형성 효과를 측정한 결과는 아닙니다.

## 검증

`node --test tests/shadow-raid.test.cjs` — 10개 통과.

- 공격·회피·반격·소환으로 끝까지 진행해 승리.
- 아무 행동도 하지 않는 플레이의 체력 소진, 회피만 하는 플레이의 시간 초과.
- 연타·게이지 부족·회피 중 공격 차단, 빠른 회피 실패와 적시 회피 성공.
- 반격 보너스 소비·만료, 단계 상승, 큰 프레임 간격에서도 누락 없는 피격 처리.
- 종료 후 추가 입력 무시·결과 1회 발생, 60초 경계에서 입력 거부.
- 동일 코드·입력 재현, 새 코드의 패턴 변화, 새 게임의 상태 초기화.
- 코드 40개에서 같은 유효 전략으로 클리어 가능.

브라우저에서 확인한 결과:

- 홈 배너 → 안내 → 시작 → 공격·회피·소환 → **40.85초 클리어 / 회피 10회**.
- 첫 시도 패배 화면 → 같은 던전 재도전 → 체력·코어·시간 초기화.
- 일시정지 중 시간 정지 → 계속하기 → 키보드 공격 반영.
- 도전 링크의 직접 복사 대체 UI → 해당 URL로 새로 열기 → 동일 코드 `BNS1FX`와 최고 기록 `40.85s` 표시.
- 한국어→영어 전환 → `/attack` 전송 → 코어 720→708, 영문 전투 로그.
- 창작마당 실행 카드와 기존 미리보기 배지 확인.

브라우저 확인은 데스크톱의 440px 게임 화면에서 수행했습니다. 실제 모바일 기기, 보조기기, 여러 기기 간 링크 공유는 별도로 실기 검증해야 합니다. 실시간 멀티플레이 검증을 수행한 것으로 보고하지 않습니다.
